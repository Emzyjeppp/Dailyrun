# Kebijakan Keamanan

## Pelaporan Kerentanan

Kami memperhatikan keamanan data dan privasi pengguna dengan serius. Jika Anda menemukan kerentanan keamanan pada repositori Dailyrun, harap laporkan secara tertutup.

Jangan membuka issue publik untuk masalah keamanan.

Kirimkan laporan melalui salah satu saluran berikut:
- Email ke pengelola proyek atau via kontak profil GitHub.
- Gunakan fitur Private Vulnerability Reporting di tab Security repositori GitHub jika tersedia.

Sertakan langkah reproduksi terperinci, versi sistem operasi, dan dampak yang mungkin timbul agar kami dapat segera mengambil tindakan perbaikan.
